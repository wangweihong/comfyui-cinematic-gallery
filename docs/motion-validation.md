# 运镜图库验证记录

日期：2026-11-04。

## 内容和生成

- 40 个规范镜头条目、7 个分类；每项包含中英文名称、通用运镜提示词、完整场景示例、镜头说明、使用场景及原名称别名。
- 首批 12 条完成本地生成与筛选，其余 28 条状态为 pending，保留文字而不允许作为视频节点输入。
- 全部使用本机 ComfyUI 0.43.0、H3 Ref2VA INT8、Qwen3-VL 32B INT8 文本编码器、H3 INT8 视频 VAE；16 步 ER-SDE、simple、CFG 1。
- 每条实际 API 工作流、种子、参数、审看说明、最终视频 SHA-256 均随素材保留。没有借用其他条目的视频或用静态图片缩放替代生成运镜。
- 侧跟、上升、后拉上升采用第 2 次生成结果；首次人物裁切或额外滚转的候选未进入素材库。

## 视频审看与检查

- 逐条检查顺序概览和包含全部帧的时间序列接触表，核对运动方向、前后景视差、主体保持关系和起止画面。
- 12 条视频全部逐帧解码，未发现黑帧或完全重复帧；相邻帧差统计见 `motion-frame-validation.json`。
- ffprobe 验证：576×320、24/1 fps、H.264、yuv420p、无音轨。10 条基础示例各 124 帧／5.166667 秒，两条组合示例各 192 帧／8 秒。
- 横移：近处红杯比远处窗户更快向左出画。前推：人物变大、近处桌面和窗外空间变化不同。仰摇：台阶、门、立柱、屋檐和天空依次进入。上升：完整人物保留，矮墙后的花园被揭示。
- 钥匙交接：跟随人物到桌边，放下钥匙后人物离开，焦点和镜头转给钥匙，最终清晰展示钥匙。后拉上升：人物变小，树冠和庭院整体显露，新版无首版末段的额外滚转。
- 这些是生成式电影示例；轨迹角度、镜头速度和人物细节不代表经过物理标定的相机测量。

## 程序和浏览器检查

- 实际 ComfyUI 容器 Python 环境运行 13 项 unittest 全部通过，包括原静态节点、目录、视频规格、原生 VideoFromFile 八输出和 HTTP Range 206。
- Node.js test runner 9 项通过，涵盖双语检索、别名、通用与示例文本、待制作随机排除、节点恢复、跨来源消息拒绝及节点类型隔离。
- 浏览器检查：40 条目录中显示 12 条可播放；待制作条目展示完整文本并禁用使用按钮；中英切换和领域切换保留各自搜索与筛选。
- 原生播放器可播放、暂停、通过时间进度条跳转；实际检查 8 秒片段暂停跳转到 4 秒，文件支持 Range 和 seekable。
- 通用提示词和完整示例分别复制成功。
- 双节点测试宿主：选择钥匙运镜不会改变图片节点；图片节点浏览运镜时“使用”禁用；保存恢复后两个编号、语言、输出标签和运镜视频各自正确恢复。
