# 摄影参考与电影参考 v0.3 验证记录

日期：2026-11-04。

## 目录与素材

- 摄影参考保留 110 张原图和原五个双语输出，节点显示名为“摄影参考”。
- 电影参考为 40 条视频、7 个分类，28 条原缺失视频均已补齐。用户清单的 29 个常用名称逐项核对见 `motion-coverage.md`，不存在仅文字占位。
- 全部视频为本地 ComfyUI H3 Ref2VA INT8 生成，576×320、24fps、无声 H.264/yuv420p，时长 5—10 秒。每条保留实际提示词、工作流、种子、参数、审看说明及最终文件 SHA-256。
- 顶部下降推近、滑动变焦、低角度、虫眼视角、推近硬切上升采用重新生成的候选，修正首版方向、裁切或动作不清的问题。虫眼视角仅将固定倒置方向归正，处理命令明确记录在生成元数据中。
- 逐条检查顺序概览，核对运动方向、主体保持关系、视角及叙事交接；40 条视频全部完整解码，无黑帧或完全重复帧。相邻帧统计见 `motion-frame-validation.json`。
- 这些是生成式镜头示例，轨迹角度、人物细节和镜头速度不代表物理标定测量。

## 新五口与兼容

- 电影参考输出为 `prompt`、`image`、`description`、`example_prompt`、`video`。三个文本输出跟随 `language`，切换语言会改变缓存指纹。
- 中文界面只显示中文镜头名、提示词、示例、说明与场景，英文界面同理；不再并列显示两种语言。中文卡片显示常用中文别名以便对照原清单。
- 旧八口界面工作流载入后，原端口按 `[0,0,1,2,2,3,3,4]` 合并，保留全部下游连线与视频连接。覆盖对象和 Map 两种链接存储，并保留原输出对象。
- ComfyUI 前端源码确认 `loadedGraphNode` 在图配置和链接载入后调用。旧 API JSON 不经过前端，需按新端口序号更新；随附示例已更新。
